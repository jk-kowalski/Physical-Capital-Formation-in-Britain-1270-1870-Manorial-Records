Physical Capital Formation in Britain, 1270-1870: Manorial Records
Kuba Kowalski, February 2026

This repository contains a set of Jupyter notebooks (Python) designed to process historical manorial records (13th–15th century), transforming scanned or transcribed Latin text into structured, analyzable datasets. Inputs and outputs are included. This repository exists solely to give examples of work from this project and does not include all scripts, inputs, nor outputs.
